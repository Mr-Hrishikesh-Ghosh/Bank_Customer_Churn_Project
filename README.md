# 🏦 Bank Customer Churn Prediction & Retention System

A machine learning-based web application that predicts bank customer churn risk and supports data-driven customer retention strategies.

## 📌 Project Overview

The **Bank Customer Churn Prediction & Retention System** is a machine learning web application designed to predict whether a bank customer is likely to leave the bank. It analyzes customer information to identify potential churn risks and help banks make informed customer retention decisions.

The application integrates machine learning models with an interactive dashboard built using Streamlit, making churn prediction accessible and easy to use.

## 🎯 Objectives

1. Predict the likelihood of customer churn using machine learning.
2. Identify customers with high, medium, and low churn risk.
3. Analyze customer characteristics that may influence churn.
4. Support data-driven customer retention strategies.
5. Provide a user-friendly interface for generating churn predictions.

## ✨ Key Features

- **Customer Churn Prediction:** Estimate whether a customer is likely to leave the bank.
- **Risk Classification:** Categorize customers into risk levels using configured thresholds.
- **Interactive Dashboard:** Enter customer details and view prediction results.
- **Machine Learning Integration:** Use a trained model pipeline to generate predictions.
- **Customer Insights:** Support the analysis of customer behavior and potential retention opportunities.
- **Report Generation:** Generate downloadable reports, if enabled in the application.

## 📊 Machine Learning Workflow

1. Collect and prepare customer data.
2. Perform exploratory data analysis (EDA).
3. Clean the dataset and engineer relevant features.
4. Train and evaluate machine learning models.
5. Save the selected model pipeline.
6. Integrate the trained model with the Streamlit application.
7. Generate churn predictions and display customer risk insights.
